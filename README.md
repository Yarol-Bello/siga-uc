# SIGA-UC — Sistema Integrado de Gestión Académica

Sistema web para la gestión académica y administrativa de la **I.E.P. Unión Científica**.

## 🏫 Información Institucional

- **Institución**: I.E.P. Unión Científica
- **Ubicación**: Huancayo, Junín, Perú
- **Año lectivo**: 2026

## 🛠️ Stack Tecnológico

| Capa | Tecnología | Versión |
|---|---|---|
| **Frontend** | Angular + Bootstrap | 21.x + 5.x |
| **Backend** | Node.js + Express | 20.20.2 LTS + 4.x |
| **Base de Datos** | PostgreSQL | 18.4 |
| **Control de Versiones** | Git | 2.56.0 |

## 👥 Roles del Sistema

| Rol | Descripción |
|---|---|
| **Administrador** | Control total del sistema |
| **Secretaría/Tesorería** | Gestión de matrículas, pensiones y caja |
| **Docente** | Registro de notas, asistencia y reportes |
| **Estudiante** | Consulta de notas, asistencia y horarios |
